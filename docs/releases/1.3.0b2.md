# v1.3.0 Beta 2 — HACS installation ZIP

This beta introduces a dedicated `sigen.zip` installation file for HACS. HACS now downloads that file instead of the automatically generated repository archive. GitHub can count downloads of this release file, allowing HACS to display download statistics after its metadata refreshes.

## Changes since Beta 1

- Added a repeatable package builder that includes the committed contents of `custom_components/sigen/` directly at the ZIP root.
- Added a release workflow that runs tests and validation, checks the tag against the integration version, uploads the installation file to a draft release, downloads and verifies it, and only then publishes the release.
- Updated manual installation instructions for the new ZIP layout.
- The Modbus polling and control code is unchanged from Beta 1.

Download counts measure file downloads per release, including reinstalls and validation downloads. Previous repository-archive downloads cannot be added to these counters.

## Requirements and testing

**Home Assistant Core 2026.10.0+ and Python 3.14.2+ are required.**

Please install this beta through HACS, restart Home Assistant, and check your existing sensors, controls, entity IDs, and configuration. Share successful upgrades as well as failures in [the beta test discussion (#432)](https://github.com/TypQxQ/Sigenergy-Local-Modbus/discussions/432). Include the previous integration version, HA version, device types, and any relevant logs/diagnostics.

For manual installation, extract `sigen.zip` directly into `custom_components/sigen/`; its files are already at the archive root.

The Remote EMS changes introduced in [#429](https://github.com/TypQxQ/Sigenergy-Local-Modbus/pull/429) remain a candidate fix for the activation/readback timing problem in [#427](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/427). The broader unavailability report remains open for diagnostics and test results.
