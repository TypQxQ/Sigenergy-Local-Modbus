# Sigenergy ESS 1.3.0b9

This prerelease fixes PV-string energy undercount after repeated unchanged power reports (#452, #453, #461).

## Changes

- Use `last_updated` between consecutive state or attribute events so unchanged reports cannot shorten an energy integration interval. Timer checkpoints retain their existing accounting.
- Preserve existing accumulated totals. Historical statistics are not rewritten or retroactively corrected.
- Load the production minimum integration interval in the event-flow tests. New two-second cases verify energy accounting and timer rescheduling before and after a timer checkpoint.

Thanks to lnafziger for reporting the undercount and contributing the original fix and regression tests.

## Upgrade and validation

- Requires Home Assistant Core 2026.10.0+ and Python 3.14.2+.
- Update through HACS and restart Home Assistant completely to load the new code.
- All 260 regression tests pass with both supported Modbus versions, 4.12.3 and 4.12.4. Codex reported no findings; Greptile scored the final code 5/5.
- The interval correction has deterministic regression coverage. A comparison against live production measurements remains pending.

The Remote EMS availability report (#427) and AC-charger connection errors (#450) remain separate investigations; this beta does not claim to resolve them.
