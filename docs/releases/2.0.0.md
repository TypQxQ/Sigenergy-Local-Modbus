# Sigenergy ESS 2.0.0

This release adds localized entity names, a battery runtime estimate and a
dedicated Energy Dashboard guide. It requires **Home Assistant Core 2026.10.0
or later** and **Python 3.14.2 or later**.

## Before upgrading

Eight status sensors now store stable keys such as `charging`. Update any
automation, template or dashboard comparison that uses the old English state
text. See the [2.0 migration guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0/docs/migrations/2.0.md)
for the full mapping. Existing entity IDs, user-defined names and energy
history are retained on upgrade. Restart Home Assistant after installation.

## What's new

- Names and setup dialogs are available in 11 languages. Choose an entity name
  language in the integration's display settings.
- **Battery time remaining** estimates the hours above backup reserve using
  household consumption and shows the inputs as attributes. When the estimate
  relies on the fallback, it shows `unknown` if a configured AC charger's
  power reading is missing or invalid.
- The [Energy Dashboard guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0/docs/ENERGY_DASHBOARD.md)
  covers grid and battery directions, plant and inverter totals, and
  third-party solar. Combined PV power and the generating indicator show
  `unknown` when an expected source reading is missing or invalid.
- Optional on and off thresholds reduce chatter in power flow indicators.
  AC charger current limits follow the charger and input-breaker ratings.
- Device address edits preserve the entity and device registry. Explicit
  removal selects devices by their registry identity. Setup rejects duplicate
  Modbus addresses on the same endpoint.
- Register discovery reuses saved support data and probes incrementally.
  PV string energy restores across restarts and handles unchanged power
  reports without shortening the integration interval.
- Readable controls show missing readings as unavailable. Power limit
  sentinels show `unknown`, and inverter power factor readback uses the
  correct sign and scale.
