# Sigenergy ESS 2.0.0b1

This beta prepares eight status sensors as Home Assistant enum sensors. It includes the previously reviewed 1.3.0b9 PV energy fix.

## Breaking change: stored sensor states

These sensors now store stable keys, such as `charging`, instead of English labels such as `Charging`:

- Plant grid sensor status and grid connection status.
- Plant and inverter running state.
- Plant EMS work mode.
- Inverter output type.
- AC charger system state and DC charger running state.

English display labels are included, but automations, templates and API consumers must compare the new stored keys. See the [complete 2.0 migration guide](../migrations/2.0.md) before upgrading.

Unrecognized register values report as Home Assistant `unknown` when the entity is otherwise available. The DC charger's documented status is `charger_unavailable`, which remains distinct from Home Assistant's `unavailable` entity state.

Existing entity IDs, device links, accumulated energy and historical records are retained. Old historical status strings are not rewritten. Remote EMS select options, write commands, alarm text and register addresses are unchanged.

## Scope and requirements

Only the eight sensor state contracts and their required English display labels change in this beta. General entity-name changes, issue #463 and additional languages are deferred.

Requirements remain Home Assistant Core 2026.10.0+ and Python 3.14.2+. Restart Home Assistant completely after an approved installation. This is a prerelease; publication and installation require the owner's explicit approval.
