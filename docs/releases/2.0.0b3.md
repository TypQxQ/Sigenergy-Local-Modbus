# Sigenergy ESS 2.0.0b3

- Add complete Danish, Dutch, Finnish, French, German, Italian, Norwegian Bokmål,
  Polish and Spanish translations alongside English and Swedish: setup/options,
  entity names, enum status labels, alarm details,
  action labels and errors. Entity IDs, stored states, control option values
  and energy history are preserved. Default entity names use the server
  language; status labels and dialogs use the interface language.
- Honor a configured one-second update interval instead of silently using five
  seconds. Setup and options reject intervals below one second; the default
  remains five seconds. Slow reads retain the existing update deadlines.
- Remove the obsolete manual accumulated-energy adjustment menu. Already-open
  adjustment forms abort with an English or Swedish explanation without saving
  requests or reloading the integration. Existing queued restore data, entity
  IDs, energy calculations and history are preserved.
- Declare config-entry-only setup to resolve the missing `CONFIG_SCHEMA`
  validation warning.

Includes all fixes from 2.0.0b2. Requirements remain Home Assistant Core
2026.10.0+ and Python 3.14.2+.
