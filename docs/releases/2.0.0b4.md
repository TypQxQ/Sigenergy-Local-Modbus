# Sigenergy ESS 2.0.0b4

- Add calculation inputs to **Battery time remaining**: household consumption
  (kW), battery and backup SOC (%), rated capacity (kWh), and usable energy above
  reserve (kWh). The estimate and attributes share the same validated cached
  inputs. No additional Modbus reads, entities or controls are added.
- Translate the five attribute labels in all 11 supported languages. Missing or
  invalid inputs are `null`; other valid inputs remain visible. Valid zeroes,
  the instantaneous estimate, existing IDs and energy history are preserved.
- Document separate confirmed-alarm and uncertainty/offline indicators in the
  [usage guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0b4/docs/USAGE.md#alarm-monitoring).
  Alarm 7's ambiguous `0xFFFF` remains **Unknown Alarm** and is not classified as
  a confirmed fault or as unsupported.
- When copying a **Battery time remaining** template, use the actual entity ID
  from its entity settings. It may be
  `sensor.garage_sigen_plant_battery_time_remaining` rather than the example
  `sensor.sigen_plant_battery_time_remaining`. A reference to a nonexistent ID
  returns `unknown`; no renaming is required.

- Reject duplicate inverter/AC charger addresses on the same host and port during
  setup and editing. Reusing an ID on another endpoint remains allowed. Errors
  are translated in all 11 languages; unchanged device settings save without
  removing or recreating entities.
- Make bundled Energy Flow gauge sensors unavailable when their required inputs
  are missing. Preserve valid zeroes, correct the battery power source/direction,
  and derive the existing battery-minutes helper from **Battery time remaining**.
  Update your copied dashboard package manually to receive these example changes.
- Add Energy Dashboard energy/power mappings, focused Recorder exclusions, AC
  charger troubleshooting and model-specific firmware notes. SigenMate SPC101
  is documented as a read-only user report, not blanket write-control support.

Includes all changes from 2.0.0b3. Requirements remain Home Assistant Core
2026.10.0+ and Python 3.14.2+.
