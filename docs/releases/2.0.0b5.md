# Sigenergy ESS 2.0.0b5

- Combined PV power and the PV-generating indicator report unknown if an
  expected source reading is missing or invalid. Valid zeroes still work, and
  sources confirmed unsupported are omitted.
- Add a [dedicated Energy Dashboard guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0b5/docs/ENERGY_DASHBOARD.md)
  for grid and battery directions, plant and inverter totals, third-party
  solar, and the optional home consumption meter.
- Add a diagnostic template for the inverter's power balance residual using
  native PV, AC and battery measurements.

Includes all changes from 2.0.0b4. Upgrading from 1.x? See the
[2.0 migration guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0b5/docs/migrations/2.0.md)
for status keys used in automations.
