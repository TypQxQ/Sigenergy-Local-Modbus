# Sigenergy ESS 2.0.2

**Before upgrading.** Requires Home Assistant Core 2026.10.0 or later. If upgrading from 1.2.x, review the [2.0 migration guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.0/docs/migrations/2.0.md) for changes to stored sensor states. Restart Home Assistant after updating.

- Modbus reads interrupted by successive writes can recover until the poll deadline. Remote EMS still verifies commands with fresh readback. [#495](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/495) · [#427](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/427)
- While an AC charger read is pending, Home Assistant gets fresh plant and inverter readings after the shorter of two seconds and the configured polling interval. Charger reads that time out are retried on the next poll. The intermittent charger timeouts in #450 remain under investigation. [#450](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/450) · [#505](https://github.com/TypQxQ/Sigenergy-Local-Modbus/pull/505)
- The built-in battery runtime estimate has been removed while its replacement is designed. Review any automations or dashboards that reference it. [Battery runtime discussion](https://github.com/TypQxQ/Sigenergy-Local-Modbus/discussions/497)
