# Sigenergy ESS 2.0.3

**Before upgrading.** Requires Home Assistant Core 2026.10.0 or later. If you
use the old **AC charger power** or **DC charging** switch in an automation,
replace the on/off actions with `button.press` on the charger's **Start charging**
and **Stop charging** buttons. Use **System state** for the AC charger and
**Running state** for the DC charger when you need to read the charging status.
Restart Home Assistant after updating.

- Fix **Consumed power** getting stuck at −0.001 kW when the device sends a
  value that means the reading is missing. Home Assistant uses the existing
  calculation in that case. **Total load power** shows `unknown` when its reading
  is missing. A real zero still shows as zero. Thanks to @wimgoeman for the
  report and patch. [#508](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/508)
  · [#509](https://github.com/TypQxQ/Sigenergy-Local-Modbus/pull/509)
- Add a [Home Assistant entity reference](https://github.com/TypQxQ/Sigenergy-Local-Modbus/blob/v.2.0.3/docs/MODBUS_ENTITIES.md)
  explaining the sensors, controls, operating modes, and equipment requirements.
- Remove the two deprecated charger switches and unused settings left over
  from the old YAML sensor setup.
