This beta targets the Modbus timeouts reported in [#514](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/514). After the first eligible read timeout, Sigenergy can reopen the shared connection and retry the block once. A second timeout stops reads on that endpoint for the current poll. If the poll reaches its deadline, Home Assistant can keep the readings that already arrived.

Diagnostics now include timeout, reconnect, and request-latency figures for each endpoint. Testing on the affected inverter is still pending.

Requires Home Assistant Core 2026.10.0 or later. Restart Home Assistant after updating through HACS. [PR #517](https://github.com/TypQxQ/Sigenergy-Local-Modbus/pull/517)
