This beta targets the AC charger sensors that go unknown for one poll at a time, reported in [#450](https://github.com/TypQxQ/Sigenergy-Local-Modbus/issues/450). When a single AC charger read times out or loses its connection, the charger sensors keep their last value for that poll instead of becoming unknown. A second missed read in a row makes them unknown as before. Plant consumption uses the same held charger power. Charger controls still require a live reading.

Diagnostics list the held registers under `held_fields`. This beta also includes the Modbus timeout recovery from 2.0.4b1. Testing on an affected charger is still pending.

Requires Home Assistant Core 2026.10.0 or later. Restart Home Assistant after updating through HACS. [PR #520](https://github.com/TypQxQ/Sigenergy-Local-Modbus/pull/520)
